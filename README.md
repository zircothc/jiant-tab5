# JIANT FM on the M5Stack Tab5

Port of [JIANT FM](https://github.com/juanjiant-bit/JIANT) (a Felucca fork for the M-Vave FM-1, v0.9.18) to the M5Stack Tab5 (ESP32-P4), with a full touch panel, USB MIDI host and MIDI learn.

GPL-3.0-only, like JIANT.

## Build

    git clone https://github.com/juanjiant-bit/JIANT.git
    cd JIANT

Then copy the `tab5` folder of this repository into `JIANT`, open `tab5/idf` in VS Code with ESP-IDF v6.1 and run **Build, Flash and Monitor**. See `tab5/EMPEZAR.md` (Spanish) for the step by step.
